Commenter archetypes taken from real comment sections, not invented

fetch_yt_comments.py reads the top comments from the Shorts this platform has
already posted -- commentThreads.list takes an API key, no OAuth, one quota
unit -- and the personas are built from what actually dominated the sample
rather than from assumptions about how people comment.

Instagram has no equivalent and is not included. Its Graph API only reaches
accounts you manage; there is no public comment read for arbitrary posts, the
same wall that blocks posting there.

Guessing produces caricature: the hater, the fan. Reading a few hundred real
ones produces shapes nobody would think to invent -- chiefly the commenter who
returns to annotate their own comment with "Edit: holy 4 months and 4K likes,
I'm famous!", which was among the highest-engagement forms in the data.

Thirteen archetypes, each carrying the verbatim comments it came from, kept in
EVIDENCE so a reader can check the persona against the source instead of
trusting the summary.

The dank register is included because the data insisted on it: the single
most-liked comment in the entire sample was "No hesitation at the end 💀" at
25,830 likes, above every sincere reaction. Leaving it out would have meant
modelling comment sections without their most popular mode. DANK_GUARD draws
the line explicitly rather than by inference, because that register is exactly
where "edgy" gets used as cover -- dark about a situation is the point, cruelty
aimed at a person is not, and a real tragedy drops the register entirely.

Two archetypes failed for reasons that were not the prompt, and both are worth
recording. The punner emitted its example verbatim however firmly it was told
not to, because its display name *was* the example: the system prompt opened
"You are KANE'T BELIEVE IT" and the model read its own name and repeated it. An
instruction cannot beat a name, so it was renamed. The edit-farmer stopped
writing edits because the honesty guard forbids stating things it was not told,
which correctly covers invented like counts -- a real conflict where the guard
won, which is the right precedence and the wrong result, now resolved by
framing the count as the bit it is.
